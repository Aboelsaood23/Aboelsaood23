## Selected projects

### [Databricks Sales Data Pipeline](https://github.com/Aboelsaood23/DataBricks-Data-Engineering-)

**Technologies:** Databricks, Delta Lake, Python, pandas, Spark, SQL.

**Current scope:** Bronze and Silver processing, plus SQL connectivity. Gold-layer business aggregations are a planned extension.

The repository also includes [MySQL schema and stored-procedure exercises](https://github.com/Aboelsaood23/SQL/tree/main/MYSQL).

A case study using **synthetic retail data** to explore revenue, customer behavior, and product performance. Combines SQL analysis with recency, frequency, and monetary segmentation to examine customer groups and purchasing patterns.

### [Sales Forecasting with SARIMAX](https://github.com/Aboelsaood23/Full_Data_Analysis_Projects/tree/main/Time-Series_Forecasting-Project)

**Technologies:** Python, statsmodels, pandas, NumPy, Matplotlib.
